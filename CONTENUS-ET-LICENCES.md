# Contenus, données et licences

Ce document distingue les éléments qui composent Petits Pas. La licence du
logiciel ne donne aucun droit sur les données traitées par une instance.

Le code source original de Petits Pas est distribué sous licence
`AGPL-3.0-or-later`. Les composants tiers conservent leur licence propre.

## Documentation et contenus éditoriaux

Sauf mention contraire, la documentation et les textes du site public sont
mis à disposition sous licence `CC-BY-SA-4.0`.

Les illustrations originales pourront être publiées sous cette même licence
lorsque leurs auteurs auront explicitement accepté cette diffusion. Les
polices, icônes et autres ressources tierces conservent leur licence propre,
qui doit être enregistrée avec la ressource.

## Données et photographies

Les données des écoles, comptes, classes, élèves et familles, les observations,
les productions d'enfants, les photographies et les carnets générés ne sont
pas placés sous une licence publique par Petits Pas. Ils restent soumis aux
droits, autorisations et règles de protection des données applicables à leur
contexte de traitement.

Le dépôt, la documentation publique, les démonstrations et les captures
d'écran ne doivent contenir que des identités et des données fictives.

La licence du code ne constitue pas une autorisation de présenter une version
modifiée comme une version officielle de Petits Pas. Une politique de marque
pourra préciser ultérieurement les conditions d'utilisation du nom et du logo.
