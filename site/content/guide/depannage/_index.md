Cette rubrique donnera un point d’entrée direct depuis le message ou le
comportement observé dans l’interface. Commencer par
[une action absente ou une page introuvable](comprendre-action-absente/), puis
choisir le domaine concerné :

- [connexion ou invitation](connexion-invitation-refusee/) ;
- [classe ou élève](classe-eleve-refuse/) ;
- [affectation ou remplacement](affectation-refusee/) ;
- [suivi, carnet ou photographie](suivi-carnet-media-refuse/).
