+++
title = "Transférer une copie locale vers le service"
description = "Organiser avec l’exploitant la création d’une nouvelle école à partir d’un ZIP."
+++

Une sauvegarde locale ou un export d’école ou de classe peut être confié à
l’exploitant pour créer une **nouvelle école** dans le service. Cette fonction
dépend de la version et de l’installation du service. La direction ne dispose
pas d’un bouton d’import et aucune école existante n’est remplacée.

## Convenir du transfert

1. Contacter la personne chargée du service pour choisir le périmètre : école
   entière ou classe pour une année.
2. Choisir ensemble la personne qui recevra la direction de la nouvelle école.
3. Préparer le ZIP dans une version compatible et le transmettre par le canal
   privé convenu. Il contient des données pédagogiques privées.
4. Pour un transfert définitif, arrêter les saisies dans l’ancien emplacement
   au moment convenu. Les deux copies ne se synchronisent pas.

L’exploitant vérifie le ZIP et consulte son contenu avant de confirmer la
création. Les identifiants et fichiers de l’école existante restent distincts.
Un ZIP de classe crée une école contenant cette seule classe ; il ne l’ajoute
pas à une école déjà présente.

## Préparer l’équipe sur le service

La personne choisie reçoit les droits de gestion de la nouvelle école, avec
son compte serveur ou un nouveau compte personnel. **Les mots de passe et les
droits du mode local ne sont pas repris.** Les noms des auteurs restent dans
l’historique, avec des comptes inactifs qui ne permettent pas de se connecter.

Pour un nouveau compte, l’exploitant peut vous envoyer un courriel avec le lien
**Choisir mon mot de passe**. Choisissez votre mot de passe personnel, puis
connectez-vous avec le nom d’utilisateur indiqué. Si le lien a expiré, utilisez
**Mot de passe oublié ?** sur la page de connexion avec votre adresse ;
l’exploitant peut aussi renvoyer le courriel sans refaire le transfert.
Si vous avez déjà choisi votre mot de passe, connectez-vous directement.
Un compte serveur déjà existant conserve ses identifiants.

Les classes non archivées sont mises en préparation. La direction doit
[inviter les collègues]({{< relref "/guide/equipe/inviter-membre/" >}}),
[attribuer les fonctions]({{< relref "/guide/equipe/attribuer-fonction/" >}}),
puis activer les classes. Avoir la direction ne rend pas automatiquement
responsable pédagogique de toutes les classes.

Les données et référentiels déjà utilisés sont conservés. Les choix futurs de
bases et le second facteur suivent les règles du service. Les classes closes
restent closes et un état historique inconnu n’est pas reconstitué.

Conservez le ZIP initial jusqu’à la vérification du transfert. Les sauvegardes
automatiques relèvent ensuite de la personne chargée du service. Pour
l’exploitation : procédure et limites dans `IMPORT-ECOLE.org` du dépôt.
