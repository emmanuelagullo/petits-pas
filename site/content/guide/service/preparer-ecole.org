+++
title = "Préparer l’école avec le premier compte de direction"
description = "Du courriel d’ouverture à une classe active confiée à son responsable."
+++

Le premier compte est personnel. Il reçoit les droits de gestion de l’école,
sans accès pédagogique automatique aux observations et aux carnets.

1. Vérifier l’école, le nom d’utilisateur et l’adresse indiqués dans le mail.
   Ouvrir *Choisir mon mot de passe*, saisir deux fois le mot de passe, puis
   *Enregistrer le mot de passe*. Sélectionner *Se connecter*, puis *Entrer*
   avec le nom d’utilisateur indiqué et le mot de passe choisi.
   Si un second facteur est demandé, [[{{< relref "/guide/equipe/second-facteur" >}}][le configurer]].
2. Ouvrir *Gérer l’école → Référentiels de l’école*, vérifier l’année et
   [[{{< relref "/guide/eleves-classes/referentiels-ecole" >}}][le choix proposé]].
   Dans *Choisir ou valider les propositions de l’école*, sélectionner
   *Voir les conséquences*, puis *Enregistrer ces choix pour l’année*.
   La préparation initiale est présentée en vert. La trame est déjà préparée ;
   une autre proposition reste possible. Si une offre manque, ouvrir
   *Pourquoi un référentiel manque-t-il ?*.
3. Dans *Gérer l’école → Créer une classe*, [[{{< relref "/guide/eleves-classes/creer-activer-classe" >}}][créer les classes]]
   pour l’année souhaitée. *Utiliser le référentiel proposé par l’école* est
   sélectionné par défaut : son nom est visible et la base est préparée avec
   *Créer et ajouter les enfants*, sans nouvelle confirmation séparée.
   Puis, dans *Équipe pédagogique → Inviter une personne*,
   [[{{< relref "/guide/equipe/inviter-membre" >}}][inviter les collègues]].
   Une classe doit exister pour préparer une fonction dans l’invitation.
4. Dans *Équipe pédagogique*, ouvrir *Ajouter une personne à cette classe*,
   choisir *Responsable de classe*, puis *Attribuer*.
   Une fonction préparée dans une invitation attend son acceptation. Une classe
   doit avoir un responsable actif pour être activée.
5. Dans *Gérer l’école*, sélectionner *Activer la classe*, puis confirmer.
   La classe est prête pour son responsable, qui peut vérifier
   [[{{< relref "/guide/eleves-classes/choisir-referentiel" >}}][sa base de travail]],
   [[{{< relref "/guide/eleves-classes/ajouter-eleves" >}}][ajouter les élèves]]
   et enregistrer une première observation.

Vous pouvez préparer l’effectif avant l’activation ou laisser le responsable
le faire après. Pour votre propre classe, attribuez-vous explicitement la
fonction *Responsable de classe* dans le même formulaire, puis activez-la.
Ouvrez ensuite *Gérer les enfants* ; poursuivez avec
[[{{< relref "/guide/service/premiers-pas" >}}][une première observation]].

Pour déléguer l’organisation à un collègue, attendre qu’il ait accepté son
invitation, puis [[{{< relref "/guide/equipe/gerer-droits-ecole" >}}][lui accorder les droits de gestion de l’école]].
Ces droits sont distincts de ses fonctions dans les classes.

Un lien expiré ou déjà utilisé se remplace depuis *Mot de passe oublié ?*
sur la page de connexion, avec l’adresse indiquée dans le mail. Si vous avez
choisi votre mot de passe, connectez-vous directement. La commande d’ouverture
refuse les adresses déjà utilisées ; elle ne rattache pas un compte existant.
Si vous possédez un autre compte, faire vérifier l’identité à utiliser avant
de poursuivre ; ne pas recréer l’école pour résoudre un problème de connexion.

Le mail porte les instructions essentielles de la version qui l’émet.
Le Guide en ligne peut être plus récent ; vérifier la version affichée dans
l’application et demander conseil à la direction si les écrans diffèrent.
