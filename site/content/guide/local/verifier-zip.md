Ce parcours concerne **Sur cet appareil**, dans une version qui propose le bouton.
Les anciennes publications, dont le programme 0.7, ne le proposent pas.
Le service de l’école ne permet pas d’ouvrir ou de remplacer sa base de cette façon.
Le statut dépend de la version publiée : les versions maintenues depuis #PWA13
visent la production sur ordinateur avec un navigateur compatible ; les essais utilisent des données fictives.

## Ouvrir pour vérifier

1. Choisissez **Vérifier un ZIP sans remplacer mon école**, même si aucune école
   n’a encore été créée sur cet appareil.
2. Sélectionnez votre ZIP puis **Vérifier le ZIP pour ouvrir une copie**. Un fichier
   invalide ou incompatible est refusé. Ce contrôle vérifie le fichier, pas la
   qualité des données pédagogiques.
3. Choisissez **Ouvrir la copie pour vérifier**. Avec le programme, cliquez ensuite
   sur **Fermer et ouvrir la copie** dans sa fenêtre.
4. Connectez-vous avec un compte du ZIP et son mot de passe. Les droits du compte
   s’appliquent comme d’habitude. L’ouverture ne donne pas la direction de l’école.

Le bandeau **Copie du ZIP à vérifier** reste visible. Consultez les classes,
observations et médias ; essayez l’impression et les fonctions qui vous intéressent.
Vous pouvez modifier cette copie. Votre ZIP d’origine, votre école habituelle et
l’école fictive ne sont pas remplacés. Les copies ne se synchronisent pas.

## Revenir ou conserver la copie

**Revenir à mon école habituelle** change d’espace, sans restaurer de données.
Avec le programme, la fenêtre se ferme puis se rouvre. Terminez vos saisies
avant de changer d’espace.

**Revenir à la copie de vérification** permet de la retrouver : dans la barre
du navigateur, ou sur la page de vérification du ZIP dans le programme.

Pour conserver les modifications, la direction de l’école peut télécharger un
ZIP depuis **Sauvegardes / transfert**. Gardez une copie hors de cet appareil :
le téléchargement préparé ne prouve pas que le fichier a été conservé.

Dans le navigateur, la copie reste dans un stockage distinct ; une nouvelle
ouverture de ZIP remplacera cette copie de vérification, après l’avertissement.
Les trois espaces partagent le profil et le quota : effacer les données du site
peut effacer toutes leurs données. La limite reste **256 Mio avant compression**.
Avec le programme, chaque ouverture prépare un dossier indépendant, conservé
après fermeture ; son chemin est indiqué dans les sauvegardes. Vous pouvez
supprimer ce dossier quand le programme est fermé et que vous avez conservé
ce que vous souhaitez garder. Ces copies contiennent des données privées et
demandent la même protection que votre école habituelle.

## Remplacer ensuite l’école habituelle

L’ouverture pour vérifier n’active jamais la copie comme école habituelle.
Téléchargez le ZIP de la copie que vous souhaitez conserver, revenez à l’école
habituelle puis suivez [Restaurer ou transférer]({{< relref "/guide/local/restaurer-paquet" >}}).
Vous devrez avoir la direction de l’école habituelle et confirmer le remplacement.
Les comptes, classes, observations et médias seront remplacés **sans fusion**.
Gardez d’abord une sauvegarde de l’école habituelle hors de l’appareil.

Si cet appareil n’a encore ni école ni compte, revenez à l’espace habituel et
vérifiez le ZIP choisi. **Utiliser ce ZIP comme école sur cet appareil** permet
de l’installer directement, avec ses comptes. Vous n’avez pas à créer une école
provisoire. Avec le programme, confirmez le redémarrage proposé.
