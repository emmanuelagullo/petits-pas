## Dans le navigateur de cet appareil

Dans une version qui propose ce bouton, choisissez **Essayer avec l’école fictive**.
Au premier accès, la même école de départ que la démonstration en ligne est
préparée dans un stockage distinct. Un bandeau indique l’espace d’essai.
Utilisez les comptes publics affichés ; n’y saisissez aucune donnée réelle.

**Revenir à mon école habituelle** recharge l’application sur ses données
habituelles. Aucun ZIP n’est restauré pour ce retour. Fermez les autres onglets :
un seul espace peut être ouvert à la fois. Terminez les saisies avant de changer.
Vos essais sont retrouvés lors d’une prochaine ouverture de l’espace d’essai.
Les deux espaces partagent cependant le quota et le profil du navigateur :
effacer les données du site peut supprimer les deux écoles.

## Avec le programme à télécharger

Cliquez sur **Essayer avec l’école fictive**, puis **Fermer et ouvrir l’autre espace**.
Le programme redémarre dans un dossier distinct de son paquet habituel. Au
premier lancement, le ZIP fourni avec cette version y est ouvert ; ensuite,
vos essais sont conservés. Le bandeau **Espace d’essai** reste visible.

**Revenir à mon école habituelle** ferme puis relance le programme sur son
paquet habituel, y compris si son emplacement avait été personnalisé.
Ne déplacez pas les dossiers pour passer d’un espace à l’autre.

## Avec une ancienne version

La release 0.7 ne comporte pas ce parcours. Faites préparer une installation
séparée avant d’importer le [ZIP fictif]({{< fichier-essai >}}).
Dans le navigateur, utilisez un autre profil. Avec le programme, une personne
compétente peut choisir un autre dossier avec `--paquet`. Une sauvegarde issue
d’une version récente peut être incompatible avec une version ancienne ; ne
forcez pas sa restauration.

## Après l’essai

L’école fictive ne devient pas automatiquement votre école réelle. Revenez à
[Démarrer]({{< relref "/demarrer/" >}}) pour préparer votre usage. Les mises
à jour de l’application conservent les essais ; elles ne remettent pas l’école
fictive à zéro. Une restauration dans l’un des espaces remplace uniquement
les données de cet espace, sans fusion. L’ouverture temporaire de votre propre
ZIP avant restauration suit [le parcours de vérification séparée]({{< relref "/guide/local/verifier-zip" >}}), dans une version qui le propose.
