Plusieurs personnes peuvent utiliser Petits Pas avec leur compte personnel,
quelle que soit la façon de travailler. La différence est l’accès aux mêmes
données depuis plusieurs appareils.

{{< parcours mode="service" titre="Avec le service de votre école" >}}
**À privilégier pour travailler depuis plusieurs appareils sur les mêmes données.**

Demandez à votre direction si Petits Pas est disponible pour votre école.
Obtenez l’adresse du service et une invitation à votre nom. Après connexion,
retrouvez votre classe ; si elle manque, demandez votre affectation à la direction.

- [Accepter une invitation]({{< relref "/guide/equipe/accepter-invitation" >}}).
- [Préparer une classe]({{< relref "/guide/eleves-classes/creer-activer-classe" >}}), selon vos droits.
- Vous préparez l’utilisation dans une école ? Demandez à votre institution si
  elle propose un hébergement. Sinon, une personne compétente peut suivre les
  [informations de mise en service]({{< relref "/dsi/" >}}).

{{< parcours mode="appareil" titre="Sur cet appareil" >}}
Les données de l’école restent sur cet appareil ; elles ne sont pas envoyées à
un service partagé. Plusieurs personnes peuvent s’y relayer avec leur compte.
Les appareils ne se synchronisent pas. Le premier téléchargement et les mises
à jour nécessitent une connexion ; conservez une sauvegarde hors de l’appareil.

### Dans le navigateur de cet appareil

[Ouvrir Petits Pas](https://petits-pas.gitlabpages.inria.fr/petits-pas-pwa/),
puis suivre les [étapes de démarrage dans le navigateur]({{< relref "/guide/local/essayer-navigateur" >}}).
L’application peut ensuite fonctionner hors ligne. L’ajout d’une icône est
proposé selon le navigateur ; il n’est pas nécessaire pour utiliser l’onglet.
Les essais actuels utilisent uniquement des données fictives.

### Avec le programme à télécharger

[Choisir le téléchargement Windows ou Linux]({{< relref "/guide/local/telecharger-programme" >}}),
puis [installer et ouvrir le programme]({{< relref "/guide/local/installer-programme" >}}).
Au premier démarrage, créer l’école et le premier compte personnel. Si l’écran
propose **Préparer aussi ma première classe**, cette option cochée prépare la
classe et vous en attribue la responsabilité. Choisissez le référentiel de départ,
qui sera proposé pour l’école et adopté par cette classe. Après validation,
ajoutez les élèves. Vous pouvez décocher l’option pour préparer seulement l’école.
Ce compte permet de gérer l’école dans l’application, sans attribuer une fonction officielle.

Ce démarrage simplifié est présent dans le code actuel ; il sera disponible dans
les publications qui l’intègrent. La version 0.7 crée d’abord l’école : préparez
ensuite la classe et affectez son responsable avec les fiches du Guide.

Dans les deux options, suivre le [parcours sur cet appareil]({{< relref "/guide/local/" >}}).

## Avant d’utiliser les données des élèves

Le code est ouvert, les données de l’école restent privées. L’utilisation sur
un appareil ne dispense pas de préparer leur protection. Consultez
[Protéger les données]({{< relref "/proteger-donnees/" >}}) avec votre école
avant toute utilisation de données réelles.
