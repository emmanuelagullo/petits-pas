Pourquoi un référentiel manque-t-il ?

Pour {{ annee }} : {% if catalogue_publie %}les bases autorisées par l’application ont été publiées.{% else %}aucune liste de bases n’a encore été publiée par l’administration du service.{% endif %} {{ nb_bases_superieures }} base{{ nb_bases_superieures|pluralize }} autorisée{{ nb_bases_superieures|pluralize }} au niveau de l’application pour cette école ; {{ choix.versions|length }} proposée{{ choix.versions|length|pluralize }} par l’école. {% if restriction_ecole %}L’école conserve une liste plus courte pour cette année.{% else %}L’école garde la liste autorisée par l’application.{% endif %}

Un fichier fourni avec Petits Pas n’est pas forcément disponible sur ce service. L’administration doit d’abord l’importer, puis l’autoriser pour l’année affichée. Sans publication annuelle, seule la trame initiale de l’école peut être proposée. Vérifiez aussi l’année et une éventuelle liste plus courte conservée par l’école.

Le choix proposé par défaut ne limite pas la liste. Pour une offre absente des bases autorisées par l’application, contactez la personne qui administre le service en indiquant l’année et le référentiel attendu. La direction ne peut ni importer une source ni élargir les autorisations de l’application.

Quel choix privilégier ?

Pour commencer, gardez les autorisations et le choix proposés par l'application. Choisissez une autre base proposée si l'équipe a un besoin pédagogique précis : les autres bases restent disponibles.

Conservez une liste plus courte seulement si l'école souhaite limiter les nouveaux choix de ses classes. Ce choix concerne toute l'école pour l'année indiquée.

À la nouvelle année, vérifiez les propositions disponibles. Les choix de l'année précédente ne sont pas recopiés automatiquement. L'import d'une nouvelle version ne bascule aucune classe.
